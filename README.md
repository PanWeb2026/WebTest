# pan-r.com – Relaunch (Testversion)

Statische Website der PANHOLZ GmbH & Co. KG, erzeugt aus dem Design-Entwurf.

- `index.html` – Startseite
- `referenzen.html` – Referenzen mit Filter
- `impressum.html`, `datenschutz.html` – Rechtstexte
- `assets/img/` – Fotos und Grafiken

Testbetrieb über GitHub Pages möglich (Branch `main`, Ordner `/`).

**Vor dem Livegang:** Schriften (IBM Plex) lokal einbinden statt über Google Fonts – die Datenschutzerklärung beschreibt bereits die lokale Einbindung.
